# RPO Verification Checklist

Use this checklist before enabling production company data.

## Questions

- Is RPO data redistributable?
- Under what licence or legal terms?
- Is attribution required?
- Are bulk exports allowed?
- Are natural-person entrepreneurs included?
- What fields must be excluded from a public API response?
- Is local caching allowed?
- Is a public API wrapper allowed?
- Are there retention or refresh restrictions for local copies?

## Suggested Request to ŠÚ SR

Subject: Request for clarification on RPO data use, redistribution, and public API wrapping

Hello,

We are evaluating the RPO register for a small public company lookup API that stores data locally and does not call upstream services at runtime.

Could you please confirm:

1. Whether RPO records may be redistributed in a local, public API cache or dataset.
2. Which licence or terms apply to the accessible RPO data.
3. Whether attribution is required and in what form.
4. Whether bulk export, local caching, and public API wrapping are allowed.
5. Whether natural-person entrepreneurs or role-holder personal data should be excluded for a public lookup service.
6. Whether there are specific fields that must not be republished.

Thank you.
